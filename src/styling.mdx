# Styling Shapley components.

Shapley component are designed to be styled as similarly to a normal html element as possible. 

## CSS 

Shapley tries to enforce minimal styling to accomplish the desired effect the intent is to allow css to be used like it normally would without issue. 

There are a couple styling guidelines should make styling easier.

- avoid rect based styling.
	- Shapes are clipped to their intrinsic shape. rect based styling *border*, *outline*, *box-shadow*, these all draw based on the bounding rect of the html element. as such parts or all of the effect will be clipped if used.
	- Backgrounds are ok. Because the shapes are clipped the background color or gradient can be set. for gradients and images it should be noted that css will lay them out within a Shape as if the shape were rectangular by default.

## Styling in JSX

Components such as [Glyph](?path=/docs/components-glyph--docs) and [Shape](?path=/docs/components-shape--docs) adopt attributes underlying elements. However these two components do this in a different methods. 

[Glyph](?path=/docs/components-glyph--docs) for example passes all non **Glyph** properties to the Glyphs **path** component. This allows for a Glyph to be treated like a path without the SVG wrapper in the dom.

In actuality under the hood there is an SVG acting as the root element. 

[Shape](?path=/docs/components-shape--docs) passes all of its non **Shape** properties to its root element. Unlike a glyph a shape adds a backing layer to any html element that accepts children. as such any properties that may be accepted by the desired html element are also acceptible to Shape. Basically you can use all of the same properties you normally would. 

In addition to passing all non Shape properties to the underlying component Shape offers an interface to modify props of intermediary components used as well. 

- **svgProps**: These props can be used to overrwrite any default prop from svg aside from viewBox, width and height. because of how often these are used they have been hoisted to be part of the Shape's root props. 
- **useProps**: All shapes utilize a [use](https://developer.mozilla.org/en-US/docs/Web/SVG/Element/use) to reference path commands. this object can be used to overwrite the base styles and behaviors. fill, stroke, strokeWidth have been hoisted to the Shape's root props.
- **pathProps**: Shapes can render non cached path commands. if a **d** property is provided Shape will also accept a path command which can be used to modify the cached declaration. useProps and a use component will still be utilized in the background layer. **pathProps** is not available if a value for **d** is not provided.
